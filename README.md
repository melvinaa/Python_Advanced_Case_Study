# Python Advanced Case Study

Repository ini berisi penyelesaian tiga studi kasus Python Advanced Topics.

## Struktur
- `case-01-analisis-nilai/` — analisis nilai, filtering, sorting, ranking.
- `case-02-iot-generator/` — streaming data sensor dengan generator dan `yield`.
- `case-03-login-security/` — RegEx, `@property`, decorator, dan audit log.

## Cara menjalankan
Masuk ke salah satu folder kasus lalu jalankan:

```bash
python main.py
```

Setiap kasus memiliki `README.md` dan bukti output program.
