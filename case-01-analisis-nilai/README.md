# Case 01 — Analisis Nilai Mahasiswa

## Masalah
Program menghitung nilai akhir mahasiswa dengan bobot tugas 30%, UTS 30%, dan UAS 40%, kemudian memfilter mahasiswa berprestasi, membuat ranking, dan menentukan mahasiswa terbaik.

## Konsep
- List comprehension untuk kalkulasi dan transformasi data.
- Lambda function untuk kunci sorting.
- Filtering dengan list comprehension.
- `sorted()` untuk pemeringkatan.

## Cara menjalankan
```bash
python main.py
```
